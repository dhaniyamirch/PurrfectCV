Install Meow File Icon for Windows

A one-time setup so downloaded .meow project files display the custom Meow cat icon in Windows File Explorer instead of the generic blank document icon.

Custom .meow File Extension Icon Associates .meow project files with the official Meow cat icon in Windows Explorer.
Windows-Specific One-Time Setup:

Because web browsers run in a secure sandbox, downloading a file cannot alter operating system file icons directly. This lightweight installer configures the .meow file icon association on your Windows device.

Installation Instructions

  1. Download the installer package (.zip) or the standalone script (.bat) below.
  2. Run install-meow-icon.bat.
  3. A confirmation screen will explain the setup. Type Y to confirm.
  4. The script safely copies the icon locally to %LOCALAPPDATA%\PurrfectCV, registers the association, and refreshes Explorer.

Safety & Permissions: Runs per-user (HKCU). Does not require Administrator rights and will not touch any other file types. An uninstaller script is included to revert anytime.

Commands executed by the installer

The installer executes the following standard Windows commands upon user confirmation:

:: 1. Copy icon to local user directory
mkdir "%LOCALAPPDATA%\PurrfectCV"
copy /Y "meow-project.ico" "%LOCALAPPDATA%\PurrfectCV\meow-project.ico"

:: 2. Register .meow file association in Windows Registry (HKCU)
reg add "HKCU\Software\Classes\.meow" /ve /d "Meow.Project" /f
reg add "HKCU\Software\Classes\.meow\OpenWithProgids" /v "Meow.Project" /t REG_SZ /d "" /f
reg add "HKCU\Software\Classes\Meow.Project" /ve /d "Meow Project File" /f
reg add "HKCU\Software\Classes\Meow.Project\DefaultIcon" /ve /d "%LOCALAPPDATA%\PurrfectCV\meow-project.ico,0" /f
reg add "HKCU\Software\Classes\SystemFileAssociations\.meow\DefaultIcon" /ve /d "%LOCALAPPDATA%\PurrfectCV\meow-project.ico,0" /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\.meow\OpenWithProgids" /v "Meow.Project" /t REG_SZ /d "" /f

:: 3. Clear icon cache database and refresh Windows Explorer
powershell -Command "[Shell]::SHChangeNotify(0x08000000, 0, [IntPtr]::Zero, [IntPtr]::Zero)"
taskkill /f /im explorer.exe
del /f /q "%LOCALAPPDATA%\IconCache.db"
del /f /q "%LOCALAPPDATA%\Microsoft\Windows\Explorer\iconcache_*.db"
start explorer.exe
