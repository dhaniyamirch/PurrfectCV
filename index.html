About Meow

Visual image and video processing in your browser.

Meow lets you build image-processing pipelines, explore intermediate stages, experiment with independent branches, annotate images, compare results, and save complete workspaces as .meow projects.

Keep the project folder structure intact when using GitHub Pages. OpenCV.js and JSZip load from public CDNs, so an internet connection is needed when the editor starts.

For bugs or unfinished features, consult TASKLIST.md and ROADMAP.md in the project folder.
